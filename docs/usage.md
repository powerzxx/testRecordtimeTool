# 耳机 Log 时间记录工具

Windows 11 上双击 `CreateDesktopShortcut.vbs` 创建桌面快捷方式，以后像打开记事本一样双击桌面图标即可运行。快捷方式直接启动 Windows PowerShell 中的错误报告启动器。双击 `StartRecorder.vbs` 也可安静启动；若启动失败，工具会显示错误提示，并将详情保存到 `%LOCALAPPDATA%\EarphoneLogTimeRecorder\startup-error.log`。也可双击 `StartRecorder.bat` 查看命令行错误。

启动后选择“打开记录文件”或“新建记录文件”，再输入按钮名称并点击“添加按钮”。新增、重命名、排序、删除按钮，以及拖入、排序、移除或清空测试步骤后，都会立即自动保存当前方案。点击“添加按钮”和按 Enter 均生效。删除按钮会同步移除对应测试步骤。“保存按钮配置”保留作为手动保存或失败重试入口。“清空当前配置”经确认后只清空当前方案，其他方案和已有记录不受影响。

顶部“设置 → 界面布局”可选择“经典布局”或“精简工作台”，立即生效。首次使用保留经典布局，之后记住所选布局。两种布局共用当前文件、方案、按钮和步骤；切换保留轮次、下一步、撤销机会、未添加的按钮名称及尚未保存的记录编辑文字，不会新增记录。

精简工作台将文件操作、按钮配置管理和记录选项收进顶部菜单，左侧保留测试方案、添加按钮、操作按钮与记录，右侧整列显示测试步骤。竖向分隔线调整左右区域宽度，左侧横向分隔线调整按钮区与记录区高度。经典布局继续使用原横向分隔线。两种布局分别保存分隔线比例，共用窗口位置与大小。原配置及旧版 window.json 仍可读取；布局选择保存到 preferences.json，分隔线比例保存在 window.json。

记录立即追加到 UTF-8 文本文件。每轮首次写入时增加 `--- 第 3 轮 ---` 这样的轮次标题，便于回看；不额外写入重做、跳轮或未完成标记。默认时间格式为 `HH:mm:ss`，勾选“毫秒时间”后使用 `HH:mm:ss.fff`。勾选“记录间隔”后，新操作记录会附带距上一次操作的秒数，例如 `[距上一步 1.250 秒]`，异常标记不改变耗时起点。重做本轮、全部重来、下一轮按钮、切换文件或方案会重新开始间隔计时；自动循环时继续计算连续步骤的间隔。选项会在下次启动时恢复。

鼠标移到记录行可编辑、取消或保存，右侧可删除。秒和毫秒格式都支持编辑。轮次标题不支持文字编辑。删除行后可在 5 秒内撤销删除。点击“清空记录”必须确认，程序先生成带时间的 `.txt` 完整备份，例如 `耳机操作记录_2026-10-22_14-30-25-123.txt`，送入 Windows 回收站并核实内容后才清空当前文件。回收站不可用或备份失败时保留原记录；若本地副本已生成但未能回收，会保留该副本。当前记录文件保留原路径，可继续记录。

恢复时在系统回收站找到对应名称，右键“还原”，备份会回到原记录目录，并以带时间的独立文件保留，不覆盖正在使用的记录。可用记事本查看，或通过工具的“打开记录文件”载入。清空回收站也会删除其中的备份。原有 `.bak` 文件保留，仍可通过“所有文件”筛选打开。

点击窗口顶部菜单栏的“使用说明”可打开内置说明书，按主题查看快速开始、快捷键、按钮与方案、步骤与轮次、异常与撤销、记录编辑、文件备份和窗口操作。说明窗口支持调整大小、滚动阅读和复制文字，按 Esc 或点击“关闭”返回。查看说明不会改变测试进度或记录，也不会触发主窗口的测试快捷键。

“标记异常”和“撤销空格”已从主界面移除，使用方法集中在说明书内，功能通过快捷键使用。按 **F8** 立即记录当时时间和 `[异常] 待补充说明`，不推进步骤、不改变轮次。异常行以红字显示，稍后可点击该行“编辑”补充说明。长按 F8 不会连发。

按 **Ctrl+Z** 可撤销最近一次空格记录，并恢复当时的轮次、下一步、已完成状态和耗时起点；撤销跨轮的最后一步也可恢复到上一轮。若这次空格新增了轮次标题，也会一并撤销。仅保留一次撤销机会；后续手动记录、异常记录、记录编辑/删除、步骤变更、方案或文件切换、轮次重置会使旧撤销失效。文件被其他程序改动时拒绝撤销，避免覆盖外部更改。输入框内 Ctrl+Z 保留文字撤销行为。

窗口启用了 Windows 高 DPI 感知，在高分辨率和缩放显示器上按系统 DPI 缩放。所有方案保存在当前 Windows 用户的 `%APPDATA%\EarphoneLogTimeRecorder\buttons.json` 中，兼容旧按钮配置。偏好和上次文件目录保存在同目录的 `preferences.json` 中。

“另存方案”将当前按钮组合和步骤顺序保存为独立方案；之后的修改自动保存到当前方案。通过“测试方案”下拉框直接切换，切换时从第 1 轮、第 1 步开始，已有记录文件保留。覆盖同名的其他方案需要确认。

“查看当前文件”用系统默认应用打开记录；“打开文件夹”打开当前文件所在目录。打开/新建记录的文件对话框会记住上次使用的目录，目录已不存在时使用系统默认位置。

右上方“测试步骤”区域支持从左侧拖入按钮，按钮竖向排列，上下拖动调整顺序，超过区域高度时可滚动查看；同一个按钮可拖入多次。右键步骤可将它移除。黄色按钮表示下一步，下方也显示下一步名称，长名称可悬停查看完整提示。窗口内每按一次空格记录一步，长按不会连续记录。输入按钮名称后可按 Enter 添加按钮；编辑记录时 Enter 用于保存记录。文本输入框和方案下拉框中的空格不触发测试。

全部步骤完成后自动回到第一步，下次按空格开始下一轮，可连续循环测试，每次按键仍只记录一步。点击“全部重来”回到第 1 轮、第 1 步；点击“重做本轮”保留当前轮次，回到第 1 步等待按空格；点击“开始下一轮”让当前显示的轮次加 1，放弃本轮剩余步骤，回到第 1 步等待按空格。三个按钮均保留已有记录，点击时不会新增记录。打开或新建记录文件、清空记录也会从第一步开始；调整测试步骤时保留轮次和待执行进度。鼠标点击仍只记录所点击的按钮，不推进空格执行进度。步骤顺序与按钮一起自动保存，兼容原来的按钮配置；重命名或删除左侧按钮时，步骤区同步更新。

开发验证：使用 Windows PowerShell 分别执行 `powershell -NoProfile -STA -ExecutionPolicy Bypass -File .\Test-Sequence.ps1`、`powershell -NoProfile -STA -ExecutionPolicy Bypass -File .\Test-Workflow.ps1` 和 `powershell -NoProfile -STA -ExecutionPolicy Bypass -File .\Test-Themes.ps1`。测试使用临时配置和记录文件，不修改个人配置；包含方案重启恢复、撤销边界和外部文件冲突、异常、精度、备份、焦点、最小窗口布局，以及两种布局切换后的状态保留、菜单操作和独立布局比例恢复检查。

`Test-RecycleBackup.ps1` 验证真实 Windows 回收站与右键还原、备份内容和编码、命名、锁定与回收失败、并发写入保护和空记录。测试只回收自己的临时副本，结束时还原这些测试文件，不清空或操作其他回收站内容。

测试区按钮保持原名称，不添加序号。“清空步骤”可一键移除测试区的全部按钮，保留轮次，不影响左侧按钮和已有记录；清空后自动保存，下次启动仍保持清空后的步骤配置。

测试区宽度和高度会随主窗口大小自动调整；放大窗口可显示更多步骤，缩小时仍可滚动查看。下方记录区也会随窗口调整大小。

拖动测试区和记录区之间的灰色横向分隔线，可手动分配两块区域的高度：向下拖扩大测试区、压缩记录区，向上拖则相反。两块区域均保留最小可用高度。

测试区显示当前轮次和下一步进度，例如：第 3 轮 · 下一步 2/5。最后一步记录成功后进入下一轮；点击“全部重来”、切换记录文件/方案或清空记录时重置为第 1 轮。普通点击、按钮重命名、增删或排序测试步骤均不会让轮次归一。启动时从第 1 轮开始；轮次标题随记录写入文件，历史轮次不会用于恢复执行进度。

关闭窗口时自动保存窗口位置、大小、最大化状态和分隔线比例，下次打开自动恢复；最小化关闭时保留最小化前的布局，更换显示器后会将窗口位置调整到可见屏幕内。布局独立保存在配置目录的 window.json 中。

测试过程中插入新步骤，仍以原来的下一步按钮继续：插在它前面的新步骤留到下一轮，插在它后面的新步骤本轮执行。本轮尚未开始时，新步骤按完整顺序执行。排序时已完成的步骤不会重复记录；删除下一步时继续执行剩余步骤，删除全部待执行步骤后，下次空格开始下一轮。清空步骤区保留轮次，重新拖入后可继续测试。

连续添加按钮时，输入名称后按 Enter，焦点会留在名称框，方便继续输入下一个名称。添加结束后，按 Esc 或点击窗口内的空白区域、普通文字标签，即可退出输入框，随后按空格执行测试步骤；输入内容会保留，切换焦点不记录步骤、不改变轮次。点击文本框、按钮或勾选项仍执行各自原有操作。记录行编辑框中的 Esc 继续用于取消编辑；点击空白处退出编辑焦点时保留尚未保存的文字。

底部状态栏仅显示“正在输入按钮名称”“正在编辑记录”“尚未选择记录文件”“正在选择测试方案”“尚无测试步骤”或“可按空格测试”。原底部的长提示及快捷键说明统一放入“使用说明”。窗口置顶和记录提示音继续可用。

开启“窗口置顶”后，另存方案、重命名、确认提示、文件选择和说明窗口会显示在主窗口前方；关闭弹窗后保留原有置顶状态。`Test-Dialogs.ps1` 使用真实弹窗检查两种布局下的窗口层级、确定/取消和嵌套弹窗。

“查看当前文件”和“打开文件夹”会打开外部程序。开启置顶时，工具暂时让出置顶，便于操作外部窗口，勾选状态保持不变；切回或点击本工具后自动恢复。中途主动取消置顶后不会自动重新开启；打开失败时恢复之前的状态。文件选择、另存、重命名和说明等内部弹窗在显示期间也暂时让出置顶，关闭后恢复。`Test-ExternalWindows.ps1` 使用独立进程窗口检查这两种布局下的外部窗口显示、已有进程复用、失败恢复及置顶开关行为。
